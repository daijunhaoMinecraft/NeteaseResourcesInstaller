# NeteaseResourcesInstaller
网易我的世界基岩版MCPACK材质安装器
# 软件特点
 - 支持回滚到原来的vanilla_netease的资源包(未在工具上改过的不算)
 - 支持多材质包的安装
 - 支持导入mcpack材质包
 - 使用iNKORE.UI.WPF.Modern的现代化UI库(Winui3风格,更美观)
 - and more...
